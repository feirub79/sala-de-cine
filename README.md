# sala-de-cine
Programa para gestionar la reserva de asientos de una sala de cine
Realizado por David Feijoo
Al ejecutar el programa se muestra el estado inicial de la sala con el valor de 0 para los asientos vacíos y de 1 para los reservados
Ingresar el valor de la fila y la columna que desea reservar
Si los valores ingresados están dentro del rango se realizará y la reserva y se mostrará en pantalla el estado actualizado de los asientos
